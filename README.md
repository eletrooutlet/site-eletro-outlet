# Site Eletro Outlet — publicação gratuita no GitHub Pages

Os arquivos do site são `index.html` e `logo.png`. Não precisa instalar programas nem contratar hospedagem.

1. Entre em [github.com](https://github.com) e crie um repositório **público** chamado `eletro-outlet`.
2. Dentro do repositório, escolha **Add file → Upload files**. Envie **index.html**, **logo.png** e **.nojekyll** da pasta descompactada. Eles devem ficar na raiz do repositório, sem uma pasta `eletro-outlet` por cima. Confirme em **Commit changes**.
3. Abra **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, selecione **main** e **/(root)** e clique em **Save**.
4. Aguarde a publicação e acesse `https://SEU-USUARIO.github.io/eletro-outlet/`, trocando `SEU-USUARIO` pelo nome da sua conta. O endereço definitivo também aparece em **Settings → Pages**.

Para atualizar o site, substitua `index.html` ou `logo.png` no repositório. As ofertas são configuradas na lista `products` perto do fim de `index.html`; ela começa vazia para não anunciar valores sem confirmação. Confira telefones e endereços no mesmo trecho antes de divulgar o link.

O GitHub Pages é gratuito para esse repositório público. Se quiser usar domínio próprio depois, o registro do domínio é contratado à parte.
